# รู้ทันโรคพืช พลัส 🌱 (Smart Plant Protection & Crop Health Dashboard)

> ระบบแดชบอร์ดอัจฉริยะช่วยวินิจฉัยและสืบค้นข้อมูลโรคพืช แมลงศัตรูพืช อาการขาดธาตุอาหาร และคลังกลุ่มกลไกการออกฤทธิ์ FRAC / IRAC รองรับทั้งการแสดงผลบนคอมพิวเตอร์และโทรศัพท์มือถือ (Mobile PWA)
> 
> *ต่อยอดและพัฒนาจากฐานข้อมูลต้นแบบ: สำนักงานเกษตรอำเภอบางกระทุ่ม กรมส่งเสริมการเกษตร*

---

## ✨ จุดเด่นของระบบ (Key Features)

### 1. 🌾 วินิจฉัยโรคพืชและแมลงศัตรูพืช (Diagnosis Module)
- ครอบคลุมพืชเศรษฐกิจสำคัญ: **ข้าว, ข้าวโพด, ทุเรียน, อ้อย, มันสำปะหลัง, ไม้ผล และพืชผัก**
- ค้นหาได้จากชื่อโรค, แมลง, หรือลักษณะอาการ เช่น ใบจุด, เพลี้ย, รากเน่า, รวงหัก
- **กล้องถ่ายภาพในตัว:** สามารถเปิดกล้องมือถือถ่ายภาพใบพืชเพื่อนำมาพรีวิวเปรียบเทียบกับฐานข้อมูล
- **เชื่อมต่อภาพตัวอย่างสากล:** ดึงภาพถ่ายจริงจากคลังภาพ Wikimedia Commons API โดยอัตโนมัติ

### 2. 🌿 วินิจฉัยอาการขาดธาตุอาหารตามตำแหน่งใบ (Plant Nutrients)
- ครอบคลุม 13 ธาตุอาหารจำเป็น (N, P, K, Ca, Mg, S, Fe, Zn, B, Mn, Cu, Mo, Cl)
- **คัดกรองตามตำแหน่งใบ:**
  - 🍃 **ใบล่าง (ใบแก่):** N, P, K, Mg, Mo
  - 🌱 **ใบบน (ใบอ่อน):** Fe, S, Zn, Mn, Cu
  - 🌸 **ยอดเจริญและผล:** Ca, B
- **ผู้ช่วยวินิจฉัยทีละขั้น (Diagnostic Wizard):** แบบสอบถาม 2 ขั้นตอน ช่วยเกษตรกรชี้เป้าธาตุที่น่าจะขาดได้อย่างแม่นยำ

### 3. 🧪 คลังกลุ่มสาร FRAC / IRAC & เครื่องมือสลับกลุ่มดื้อยา (MoA Hub)
- ฐานข้อมูลกลไกการออกฤทธิ์ทางชีวเคมีตามมาตรฐาน **FRAC 2026** (สารกำจัดโรคพืช) และ **IRAC 11.5** (สารกำจัดแมลงและไร)
- **เครื่องมือช่วยสลับกลุ่มสารเคมี (Resistance Rotation Helper):**
  - เลือกกลุ่มสารที่เพิ่งฉีดพ่นไปล่าสุด
  - ระบบจะแจ้งเตือน ⛔ **"ห้ามใช้กลุ่มนี้ซ้ำ"**
  - แนะนำ ✅ **"กลุ่มสารทางเลือกที่ปลอดภัย"** (กลไกต่างกัน ไม่เกิดการดื้อยาข้ามกลุ่ม)

### 4. 🧮 เครื่องคำนวณอัตราผสมสารเคมี & สมุดบันทึก (Tank Mix Calculator & Diary)
- คำนวณปริมาณสารเคมีต่อน้ำในถังพ่น (16 ลิตร, 20 ลิตร, 200 ลิตร, 1,000 ลิตร หรือกำหนดเอง)
- คำนวณพื้นที่ที่ฉีดพ่นได้ (ไร่/งาน)
- **สมุดบันทึกประวัติการพ่น (Spray Diary):** บันทึกประวัติลงในเครื่องเพื่อช่วยเตือนความจำ

### 5. 📱 ออกแบบสำหรับมือถือ (Mobile-First Responsive & PWA Ready)
- แถบนำทางด้านล่าง (Bottom Tab Bar) 5 ปุ่ม ควบคุมง่ายด้วยมือเดียว
- รองรับการติดตั้งแบบ **Add to Home Screen (PWA)** เปิดใช้งานได้เสมือนแอปแท้
- ทำงานแบบ **Offline Cache** ผ่าน Service Worker แม้ไม่มีอินเทอร์เน็ตในแปลง
- ปรับขนาดตัวอักษรได้ (ก- / ก+) สำหรับเกษตรกรและผู้สูงอายุ
- รองรับโหมดมืด (Dark Mode) สบายตา

## 📂 โครงสร้างโปรเจกต์ (Project Structure)

```
pieanplant/
├── index.html                 # หน้าหลักแดชบอร์ด (Single-Page Application)
├── manifest.json              # Web App Manifest สำหรับติดตั้งบนมือถือ (PWA)
├── sw.js                      # Service Worker (Network-First + Offline Cache)
├── css/
│   └── style.css              # สไตล์โมเดิร์นคลีน Responsive, Dark Mode, Print Stylesheet
└── js/
    ├── data.js                # ฐานข้อมูลศัตรูพืช, ธาตุอาหาร และกลุ่มสารเคมี FRAC/IRAC
    ├── app.js                 # ระบบนำทางหลัก, สลับธีม, ตัวปรับฟอนต์, ค้นหา
    ├── diagnosis.js           # ระบบค้นหา วินิจฉัย และเชื่อมคลังภาพ Wikimedia
    ├── nutrients.js           # ระบบวิเคราะห์ธาตุอาหารตามตำแหน่งใบ & Wizard
    ├── moa.js                 # คลังกลุ่มสาร FRAC/IRAC & Rotation Helper
    └── calculator.js          # เครื่องคำนวณอัตราผสมสาร & สมุดบันทึกประวัติ
```

## 🚀 วิธีการติดตั้งและใช้งาน (Getting Started)

1. **โคลนคลังโค้ดนี้:**
   ```bash
   git clone https://github.com/<YOUR-USERNAME>/<YOUR-REPO-NAME>.git
   cd pieanplant
   ```

2. **เปิดใช้งาน:**
   - ดับเบิลคลิกเปิดไฟล์ `index.html` บนเว็บบราวเซอร์ได้ทันที
   - หรือรันผ่าน Local Server เช่น:
     ```bash
     python -m http.server 8080
     ```
     แล้วเข้าไปที่ `http://localhost:8080`

3. **ติดตั้งลงหน้าจอมือถือ (PWA):**
   - เปิดเว็บไซต์บนมือถือ (Chrome หรือ Safari)
   - กดปุ่มเมนูของบราวเซอร์ แล้วเลือก **"เพิ่มลงในหน้าจอหลัก" (Add to Home Screen)**

## 📜 แหล่งอ้างอิงและมาตรฐานความปลอดภัย
- สำนักงานเกษตรอำเภอบางกระทุ่ม จังหวัดพิษณุโลก กรมส่งเสริมการเกษตร
- กรมวิชาการเกษตร: ฐานข้อมูลวัตถุอันตรายทางการเกษตรที่ขึ้นทะเบียนในประเทศไทย
- FRAC (Fungicide Resistance Action Committee) Code List 2026
- IRAC (Insecticide Resistance Action Committee) MoA Classification Version 11.5
